# ZapretTG

Портативное Windows-приложение, которое в одном окне управляет:

* **Zapret** — [Flowseal/zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube) (обход блокировок Discord/YouTube);
* **TG Proxy** — [Flowseal/tg-ws-proxy](https://github.com/Flowseal/tg-ws-proxy) (локальный MTProto-прокси для Telegram Desktop).

Скачал → распаковал → запустил `ZapretTG.exe` → пользуешься.

## Возможности

**Zapret**
* сам скачивает последний релиз с GitHub и проверяет SHA-256;
* находит все стратегии `general*.bat` и перебирает их: запуск → проверка соединения → результат → остановка;
* живой журнал перебора, прогресс «Проверяется N из M», копирование / сохранение / очистка лога, автопрокрутка;
* режимы: «до первой полностью рабочей» (по умолчанию) или «полный перебор — выбрать лучшую»;
* запуск / остановка / перезапуск / обновление, Game Filter, ручной выбор конфигурации;
* после обновления zapret конфигурация подбирается заново автоматически.

**TG Proxy**
* сам скачивает официальный `TgWsProxy_windows.exe` и проверяет SHA-256;
* показывает IP, порт, secret и готовую ссылку `tg://proxy?...`;
* «Копировать ссылку», «Открыть в Telegram» (через обработчик `tg://` Windows);
* смена порта, генерация нового secret, статус обновляется автоматически.

**Компоненты**
* до запуска окна проверяется WebView2 Runtime; если его нет — нативное окно с выбором:
  «Скачать и установить автоматически» (с указанием источника) / «Открыть официальную страницу» / «Проверить снова» / «Отмена»;
* загрузка только с адресов Microsoft, перед запуском установщика проверяется подпись Authenticode (подписант — Microsoft Corporation).

## Портативность

Все файлы — в папке рядом с exe:

```
ZapretTG.exe
data\
  settings.json      настройки
  zapret\            релиз zapret-discord-youtube
  tgproxy\           TgWsProxy_windows.exe + TgWsProxy_data\ (его конфиг)
  logs\              журналы
  webview\           профиль WebView2
  downloads\         временные загрузки
```

Нет инсталлятора, записи в `Program Files`, реестра и служб приложения. Работает с флешки
(папка должна быть доступна для записи). При закрытии окна zapret и TG Proxy останавливаются.

## Что нужно системе

| Компонент | Нужен? | Почему |
|---|---|---|
| Windows 10/11 x64 (или ARM64) | да | |
| Права администратора | да | WinDivert (часть zapret) загружает драйвер; exe запрашивает их через манифест |
| Microsoft Edge WebView2 Runtime | да | движок окна; в Windows 11 есть всегда, в Windows 10 — почти всегда |
| Visual C++ Redistributable | **нет** | exe собран со статическим VC runtime (CI проверяет, что зависимости нет) |
| .NET Runtime | **нет** | не используется |

## Как это устроено

* **Запуск стратегий.** Приложение читает выбранный `general*.bat`, подставляет `%BIN%`, `%LISTS%`,
  `%GameFilter*%` ровно как cmd и запускает `bin\winws.exe` напрямую — без консольных окон и
  без встроенной проверки обновлений `service.bat` (она открывает браузер). Сам `.bat` не меняется,
  поэтому новые стратегии из новых версий подхватываются автоматически. Если формат файла изменится
  и разбор не удастся, запускается сам `.bat` через `cmd.exe` (`NO_UPDATE_CHECK=1`).
  Так же, как `service.bat`, создаются пользовательские списки `lists\*-user.txt` и включаются TCP timestamps.
* **Проверка стратегии** (`src-tauri/src/tester.rs`). Цели — из `utils\targets.txt` самого zapret
  (тот же список, что у официального `test zapret.ps1`): Discord, YouTube, Google, Cloudflare.
  Каждый адрес проверяется дважды — с TLS 1.2 и TLS 1.3, запрос считается успешным, если пришёл
  HTTP-ответ и первые 64 КБ тела дочитались без обрыва (это ловит и блокировку по SNI, и обрыв ~16 КБ).
  Перед перебором — замер без zapret для сравнения. Лучшая стратегия: больше всего успешных проверок,
  при равенстве — меньшая задержка.
* **TG Proxy.** Используется официальный exe в его собственном portable-режиме (`TgWsProxy_data` рядом с exe).
  Приложение пишет туда `config.json` (127.0.0.1, порт, secret, `check_updates: false`) и отметки
  первого запуска — TgWsProxy стартует без своих диалогов (остаётся только его значок в трее).
  Ссылка формируется так же, как в самом tg-ws-proxy: `tg://proxy?server=127.0.0.1&port=<порт>&secret=dd<secret>`.
  Это **локальный** прокси: ссылка работает в Telegram Desktop на этом же компьютере.
* **Обновления.** `api.github.com/repos/<repo>/releases/latest` → файл релиза с `github.com/Flowseal/...` →
  сверка размера и SHA-256 из поля `digest`, которое GitHub публикует для каждого файла релиза.
  Другие адреса загрузки отклоняются. При обновлении zapret переносятся пользовательские списки
  и настройка Game Filter.

| Файл | Что внутри |
|---|---|
| `src-tauri/src/main.rs` | старт, проверка компонентов, окно, остановка при выходе |
| `src-tauri/src/deps.rs` | обнаружение WebView2/VC++, загрузка, проверка подписи, нативное окно |
| `src-tauri/src/github.rs` | релизы GitHub, загрузка, SHA-256 |
| `src-tauri/src/zapret.rs` | установка/обновление, разбор `.bat`, winws, перебор |
| `src-tauri/src/tester.rs` | проверка доступности сайтов |
| `src-tauri/src/tgproxy.rs` | TgWsProxy: конфиг, запуск, статус, ссылка |
| `src-tauri/src/winproc.rs` | процессы Windows, открытие ссылок |
| `ui/` | интерфейс (HTML/CSS/JS без сборщика) |

В приложении нет PowerShell-скриптов, обфускации и бинарников без исходников. Сторонние программы
(winws.exe, WinDivert, TgWsProxy_windows.exe) не входят в архив приложения — они скачиваются
с официальных страниц релизов авторов.

## Сборка

Нужны Rust (stable, MSVC) и Visual Studio Build Tools с компонентом «C++». Node.js не нужен.

```bat
cd src-tauri
cargo build --release
```

Готовый файл: `src-tauri\target\release\ZapretTG.exe`. Сборка релизных архивов — `.github/workflows/build.yml`
(push тега `v*` публикует релиз с zip и `.sha256`).

## Ограничения и замечания

* Антивирусы иногда реагируют на `WinDivert64.sys` / `winws.exe` — это особенность самого zapret.
* Если zapret уже установлен службой через `service.bat → Install Service`, приложение предупредит
  о конфликте: удалите службу через `service.bat → Remove Services`.
* Одновременно может работать только один TgWsProxy: закройте установленный отдельно экземпляр.
* DNS-подмену провайдера zapret не исправляет — при проблемах используйте DoH/другой DNS в системе.
